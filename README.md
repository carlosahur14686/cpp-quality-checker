# C++ Quality Checker

A small C++ console application that evaluates production measurements against tolerance limits.

## What it demonstrates

- C++ classes and structs
- Vectors
- Functions and encapsulation
- Input data validation
- Quality-control logic
- Tolerance calculations
- Summary reporting
- Technical problem solving

## Features

- Checks measurements against a target value
- Applies configurable tolerance limits
- Reports PASS / FAIL for each part
- Calculates deviation from target
- Summarizes total passed and failed measurements
- Computes pass rate

## Compile

```bash
g++ -std=c++17 main.cpp -o quality_checker
```

## Run

```bash
./quality_checker
```

## Project purpose

This repository connects C++ programming with practical quality-control and measurement logic. The example measurements are fictional and contain no private production information.
